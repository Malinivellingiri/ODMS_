How It Works

From registration to request updates.

1. Register

Create a Donor or Recipient account with the required details.

2. Login

Enter your email, password and select your role.

3. Add Organ Details

Donors select the organ they are willing to donate. Recipients select the organ they need.

4. Submit Request

Recipients submit an organ request and select its urgency.

5. Matching

The system checks available donor records for the requested organ and configured compatibility factors.

6. Notifications

Each user receives notifications connected to their own account and activity.
